# Agentic File Sorter (`AgenticFIleSorter`)

Repo: [github.com/eosterloh/AgenticFIleSorter](https://github.com/eosterloh/AgenticFIleSorter) · February 2026 · Python, Ollama, LangChain, watchdog.

Local macOS file-routing agent using Python (`watchdog`, `pathlib`, `shutil`), Ollama, and LangChain to inspect new files by content and classify/move them into organized directories offline.
